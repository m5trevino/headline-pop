What Is Headline Spotlight?

Headline Spotlight is a modular Python toolkit and desktop application for creating spotlight-style videos from images containing text. It extracts text with precise pixel coordinates, applies visual effects like blur and shadow, and produces smooth animated MP4 videos with a zoom effect.

Think of it as a focused tool: you have a screenshot, article, or image with text on it. You want to draw attention to a specific word or headline. Headline Spotlight lets you click on that text, apply effects, and generate a polished video — all in one pipeline.

Core Features

  • Word-level OCR with pixel-accurate bounding boxes
  • Click-to-select text in a visual image viewer
  • Gaussian blur on background images
  • Transparent text extraction as PNG cutouts
  • Drop shadow generation on text layers
  • Semi-transparent highlight rectangles
  • Spotlight compositing (sharp text + blurred bg)
  • Smooth zoom animation (frame-by-frame scaling)
  • MP4 video encoding via FFmpeg
  • GUI dashboard with live preview
  • Background-thread rendering (non-blocking)
  • Comprehensive error handling (no terminal errors)
  • Modular architecture — use CLI or GUI
  • Zero-copy pipeline — originals never modified

Installation

System Requirements

  • Python 3.11+ (tested on 3.11, 3.12)
  • Tesseract OCR 5.x (system package)
  • FFmpeg 5.x (system package, for video encoding)
  • Linux, macOS, or Windows with display (for GUI)

Install Tesseract (Linux)

$ sudo apt install tesseract-ocr ffmpeg python3-pip

Install Tesseract (macOS)

$ brew install tesseract ffmpeg

Install Python Dependencies

$ pip install -r requirements.txt

Install Python Packages (Manual)

$ pip install pytesseract Pillow opencv-python-headless numpy
ℹ️ Headless / Server Use
Use opencv-python-headless instead of opencv-python if running without a display. The GUI requires a display server.

Your First Render

Here's the fastest path from image to spotlight video:

Option A: Dashboard GUI (Recommended)

shell$ python3 dashboard.py

# 1. Click "Browse..." → select your image
# 2. Click window opens → click on the text you want
# 3. Tick effects (Blur, Shadow, Highlight)
# 4. Click "Render" → wait → get headline_pop.mp4

Option B: Command Line (Full Pipeline)

shell$ # Step 1: Extract OCR data
$ python3 ocr_extract.py article.png -o article.json

$ # Step 2: Run the full pipeline
$ python3 orchestrator.py \
    --image article.png \
    --ocr article.json \
    --click-x 150 --click-y 40 \
    --blur --shadow \
    --frames 60 --fps 30

# Output: headline_pop.mp4

Option C: Modular (Build Your Own)

shell$ # Blur the background
$ python3 blur_engine.py article.png -k 20 -o blurred.png

$ # Extract text at click point
$ python3 headline_mask.py article.png article.json 150 40 -o text.png

$ # Composite spotlight
$ python3 spotlight.py blurred.png text.png -o composite.png

$ # Generate animation frames
$ python3 frame_generator.py composite.png -n 60 -o frames/

$ # Assemble video
$ python3 video_assembler.py frames/ --fps 30 -o output.mp4

Dashboard Application

The dashboard (dashboard.py) is the main user-facing application. It provides a unified interface for selecting images, choosing text, applying effects, and rendering videos — all through a clean dark-themed GUI.

UI Layout

📂 Image Selection

Browse for an image file. Opens the selection GUI, click on the word, get coordinates.

🎯 Selection Coordinates

Shows the captured X,Y coordinates of your text selection in real-time.

⚡ Effects

Three checkboxes: Blur (background), Shadow (text depth), Highlight (background glow).

🎬 Render

Launches the full pipeline in a background thread. Status bar shows progress. Alerts on completion.

Error Handling

The dashboard includes a hardened error handler that captures all pipeline errors and surfaces them through the GUI. Users never see terminal output — every error is displayed in a user-friendly dialog with the technical log available for debugging.

✅ Zero Terminal Errors
All errors — OCR failures, missing files, timeout, encoding errors — are captured and displayed in the dashboard's error dialogs. The technical error log is always available for debugging.

Image Selection

The selection workflow connects the dashboard to the image viewer. When you click "Browse" and select an image:

  1. A separate Selection GUI window opens showing your image at a readable size
  2. Hover over the image to see live coordinates in the status bar
  3. Click once on the word or text you want to spotlight
  4. The window closes automatically after the first click
  5. Coordinates are returned to the Dashboard and displayed in the status area
ℹ️ Coordinate Precision
Coordinates are captured in the original image pixel space. Images that need to be scaled to fit the window have their coordinates mapped back to the original resolution.

Effects

Three composable visual effects can be toggled independently:

🌫️ Blur

Applies a Gaussian blur filter to the entire background image. This de-emphasizes the background and draws the eye to the selected text. Uses OpenCV's GaussianBlur with a default kernel size of 15 pixels. The original image file is never modified.

🌑 Shadow

Adds a depth effect to the extracted text by creating an offset, blurred, semi-transparent black layer behind the text. Configurable offset distance, blur softness, and opacity. The shadow is positioned so it never obscures the text itself.

🟨 Highlight

Draws a semi-transparent rectangle behind the selected text, creating a highlight/backdrop effect. Default color is yellow (255,255,0) at 50% opacity. Custom RGB color and opacity are supported via CLI. The rectangle is padded around the full multi-word selection.

Rendering

When you click "Render" in the dashboard, the pipeline runs in a background daemon thread, keeping the UI fully responsive. The status bar updates with progress, and a success/failure dialog appears when the video is done.

FAQ

What image formats are supported?

PNG and JPG/JPEG. PNG is recommended for images with text where you want clean edges.

Can I use this without a display (headless)?

Yes. All CLI modules work headlessly. The dashboard GUI and selection GUI require a display server. Use the CLI modules directly for server-side rendering.

How large can my images be?

The frame generator scales images proportionally. Very large images (4K+) will produce large output videos. For production use, consider resizing input images before processing.

Can I customize the zoom animation?

Yes. The frame generator supports --start-scale and --end-scale CLI arguments. The orchestrator uses defaults of 1.0× to 1.6×.

Can I change the highlight color?

Yes. Use highlight_rect.py --color R,G,B to set any RGB color. The default is yellow (255,255,0).

What if OCR doesn't detect my text?

Ensure your image has sufficient resolution and contrast. The selection GUI lets you hover over the image to see coordinates before clicking, so you can verify the text is visible. Try running ocr_extract.py directly to see the raw OCR output.

Is the original image modified?

No. All processing creates new output files. The original image is read but never written to.

System Architecture

Headline Spotlight is built on a modular, zero-knowledge pipeline architecture. Each effect is a standalone Python script that communicates through file I/O and command-line arguments. The orchestrator coordinates the flow but has zero knowledge of how individual effects are implemented internally.

Module Reference

ocr_extract.py — OCR Coordinate Extraction

Loads an image, runs Tesseract OCR, and outputs structured JSON with every detected word and its bounding box.

shell$ python3 ocr_extract.py <image> [-o <output.json>]

# Output: JSON array of { "text": "...", "box": [x, y, w, h] }
ArgumentTypeDefaultDescription
image_pathpositional—Path to input image
--output, -ostring<base>.jsonOutput JSON path

blur_engine.py — Background Image Blur

Applies Gaussian blur to an image using OpenCV. Original file is never modified.

shell$ python3 blur_engine.py <image>> [-k <kernel>] [-o <output.png>]
ArgumentTypeDefaultDescription
--kernel-size, -kint (odd, ≥3)15Gaussian kernel size
--output, -ostring<base>_blurred.pngOutput image path

headline_mask.py — Text Region Extraction

Extracts the bounding box region of selected text as a transparent PNG.

shell$ python3 headline_mask.py <image> <ocr.json> <click_x> <click_y>> [-p <padding>]

spotlight.py — Spotlight Compositing

Composites a blurred background with a sharp text overlay.

shell$ python3 spotlight.py <blurred.png> <text.png> [-o <output.png>]

drop_shadow.py — Drop Shadow Generator

Adds an offset, blurred, semi-transparent shadow behind a text PNG.

shell$ python3 drop_shadow.py <text.png>> [-ox <x>] [-oy <y>] [-b <blur>] [-o <opacity>]

frame_generator.py — Motion Generator

Generates sequential frames with smooth scaling for zoom animation.

shell$ python3 frame_generator.py <image> [-n <frames>] [--start-scale <s>] [--end-scale <s>]

video_assembler.py — Video Encoder

Compiles frame sequence into MP4 using FFmpeg.

shell$ python3 video_assembler.py <frames_dir> [--fps <fps>] [-o <output.mp4>]

highlight_rect.py — Highlight Rectangle

Draws a semi-transparent highlight rectangle behind selected text.

shell$ python3 highlight_rect.py <image> <ocr.json> <click_x> <click_y>> [-p <padding>] [-c R,G,B]

orchestrator.py — Full Pipeline Controller

Coordinates the entire pipeline: OCR → effects → compositing → animation → encoding.

shell$ python3 orchestrator.py \
    --image article.png \
    --ocr article.json \
    --click-x 150 --click-y 40 \
    --blur --shadow --highlight \
    --frames 60 --fps 30
ArgumentRequiredDefaultDescription
--image, -iYes—Input image path
--ocr, -oYes—OCR JSON file
--click-xNo50Click X coordinate
--click-yNo30Click Y coordinate
--blurNoFalseEnable background blur
--shadowNoFalseEnable text shadow
--highlightNoFalseEnable highlight rectangle
--framesNo60Number of animation frames
--fpsNo30Video frame rate

Data Format

OCR output uses a simple JSON array format:

json[
  {
    "text": "Headline",
    "box": [10, 20, 150, 40]
  },
  {
    "text": "Spotlight",
    "box": [170, 20, 120, 40]
  }
]
FieldTypeDescription
textstringThe detected word text
boxarray[x, y, width, height] in pixel coordinates

Click coordinates from the selection GUI use the same pixel coordinate space as the box values.

Troubleshooting

"ModuleNotFoundError: No module named 'pytesseract'"

$ pip install pytesseract

"ModuleNotFoundError: No module named 'cv2'"

$ pip install opencv-python-headless

"tesseract: command not found"

Tesseract is not installed or not in your PATH. Install it via your system package manager:

$ sudo apt install tesseract-ocr

"ffmpeg: command not found"

$ sudo apt install ffmpeg

"Cannot open shared object file" (OpenCV)

Missing system libraries for OpenCV. Try:

$ sudo apt install libglib2.0-0 libsm6 libxrender1 libxext6 libgl1

GUI won't open (display error)

Running without a display server. Use CLI modules directly, or set DISPLAY=:0 if running via SSH.

OCR detects wrong text or misses words

Try adjusting image resolution, ensure good contrast, or use --show-all-hitboxes with ocr_match.py to debug coordinate mapping.

Video output is empty or black

Check that frame files exist in the output directory and are valid PNGs. Run frame_generator.py separately to verify.
